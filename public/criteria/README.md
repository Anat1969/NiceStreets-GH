# תמונות הקריטריונים

התמונות שבתיקייה הזו מופיעות לצד שבע השאלות במסך "לבחור", בצד ההתחלה של כל
שורה. הקבצים הנוכחיים הם **מצייני מקום**: רישומי קו פשוטים שנועדו להחליף
בתצלומים או באיורים של אשדוד.

## מה נדרש

קובץ אחד לכל שאלה, בשם המדויק שבטבלה. הקוד טוען אותם לפי שם השאלה, ולכן אין
צורך לשנות קוד בהחלפה.

| קובץ | השאלה | מה כדאי שייראה בתמונה |
|---|---|---|
| `shade.svg` | צל | חופת עצים רציפה מעל מסלול הליכה, בשעת צהריים |
| `walking.svg` | הליכה וחצייה | מדרכה רחבה ורציפה, ומעבר חצייה נגיש |
| `frontages.svg` | חזיתות | חזית מבנה עם חלונות וכניסות במפלס הרחוב |
| `staying.svg` | מקום לשהות | ספסל או פינת ישיבה שאנשים באמת יושבים בה |
| `mix.svg` | עירוב שימושים | מסחר ומגורים באותו ציר |
| `maintenance.svg` | תחזוקה | מדרכה שלמה, תאורה תקינה, ריהוט רחוב מטופח |
| `safety.svg` | ביטחון | רחוב מואר בשעת ערב, עם נוכחות אנשים |

## דרישות טכניות

- **יחס:** ריבוע. התמונה מוצגת ב-44×44 פיקסלים, ולכן היא צריכה לעבוד גם בקטן.
- **פורמט:** `.svg` מועדף. אם מחליפים ל-`.jpg` או `.png`, יש לעדכן את הסיומת
  ב-`components/ChooseFlow.tsx` (הנתיב `/criteria/${question.key}.svg`).
- **גודל קובץ:** עד 60KB לתמונה, כדי שהמסך ייטען מהר גם ברשת סלולרית.
- **קריאות:** הנושא צריך להיות מזוהה גם בגודל 44 פיקסלים. תצלום רחב עם הרבה
  פרטים לא יעבוד; עדיף תקריב על הדבר עצמו.

## נגישות

התמונות הן **קישוט בלבד**: הן מוצגות עם `alt=""` ואינן נקראות בקורא מסך,
משום שטקסט השאלה וההסבר שלידה נושאים את כל המשמעות. אין להכניס לתמונה טקסט
שהוא המידע היחיד.

## זכויות

יש להשתמש רק בתצלומים שלעירייה יש בהם זכויות שימוש, או ברישיון שמתיר שימוש
ציבורי. מומלץ לתעד את מקור כל תמונה בקובץ הזה בעת ההחלפה.
