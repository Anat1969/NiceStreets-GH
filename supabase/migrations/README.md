# migrations

כל שינוי סכמה נכתב כאן כקובץ, ומוחל לפני הדחיפה.

שם הקובץ הוא `<version>_<name>.sql`, כשה-version הוא חותמת הזמן שבה השינוי
הוחל, בפורמט `YYYYMMDDHHMMSS` — אותו מזהה שמסד הנתונים שומר אצלו. כך אפשר
להשוות את התיקייה הזאת מול רשימת ההגירות במסד ולראות מיד אם משהו חסר.

## ארבע הגירות שקדמו לתיקייה הזאת

הן הוחלו על המסד לפני שהוחלט לנהל את ההגירות בקבצים, ולכן אין להן קובץ כאן:

| version | name |
|---|---|
| 20260924202924 | good_streets_schema |
| 20260924202954 | good_streets_rls |
| 20260924211022 | app_role_write_access |
| 20260925112056 | canonical_streets |

**התיעוד המאוחד שלהן הוא `supabase/schema.sql`** — הוא מתאר את מצב הסכמה
המלא אחרי ארבעתן, והוא גם מה שמריצים כדי להקים מסד נתונים חדש מאפס. הוא
לא שוחזר לארבעה קבצים נפרדים משום שה-SQL המקורי של כל אחת מהן לא נשמר,
ושחזור מהזיכרון היה תיעוד שגוי שנראה אמין.

מכאן והלאה: כל שינוי מקבל קובץ.
