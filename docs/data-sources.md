# מקורות נתונים פתוחים לבדיקה אוטומטית של רחובות אשדוד

**מטרה:** שהצוות לא יבדוק ביד מה שאפשר למדוד אוטומטית (ענת, סעיף 12).
נבדק 09.11.2026. כל מקור סומן: **אומת** (נשלף בפועל), **אומת חלקית** (רשומת המאגר נשלפה, הקובץ לא), או **לא אומת**.

**איך נבדק:** סביבת העבודה חסומה לרוב האתרים. הבדיקה נעשתה דרך הרחבת `http` של מסד הנתונים (Supabase, מחוץ לישראל).
**ממצא חשוב:** ה-API של data.gov.il עונה רק עם כותרת `User-Agent`; בלעדיה מתקבל 404. כך:

```sql
select (extensions.http(('GET','https://data.gov.il/api/3/action/package_show?id=nationalcanopytrees',
  array[extensions.http_header('User-Agent','datagov-external-client')],null,null)::extensions.http_request)).content;
```

## השורה התחתונה

==שלושה מקורות לאומיים פתוחים מכסים כבר היום את שלוש שאלות הסף: צל, הליכה בטוחה וביטחון.==
1. **מיפוי חופות עצים** (מפ"י) — כבר מחושב "כיסוי חופות ברחובות". מחליף את הניחוש בצל.
2. **תאונות דרכים עם נפגעים** (הלמ"ס) — לכל תאונה יש **סמל רחוב** (REHOV1), אותו סמל שבמרשם שלנו, ונקודה ב-ITM. חיבור ישיר, בלי התאמת שמות.
3. **OpenStreetMap** — עסקים, ספסלים, מעברי חצייה, בניינים. כבר בשימוש לחתך.

אתר עיריית אשדוד ושרתי מינהל התכנון **אינם נגישים מחוץ לישראל**, ולכן שכבות עירוניות ממשיכות לעבור בבקשה (`docs/gis-layers-request.md`).

## איך מושכים את זה בפועל

- **מ-data.gov.il:** GitHub Action (רץ בארה"ב, כמו `fetch-sections.yml`). API עם `User-Agent`; קבצי ZIP מ-`e.data.gov.il`.
- **מ-OSM:** כמו היום.
- **ממקורות שחסומים מחוץ לישראל** (עירייה, מבא"ת): הורדה ידנית פעם ברבעון, או בקשה מאגף ה-GIS.
- **שמירה:** תוצאות מחושבות ב-`public/geo/` או בטבלת `streets.gis`, עם תאריך המקור. מנוע הבדיקה כבר מתריע על נתון בן יותר מ-3 שנים.
- **ייחוס בממשק:** כל ערך אוטומטי מוצג עם המקור והתאריך שלו, בקטן, בסוף הדף.
